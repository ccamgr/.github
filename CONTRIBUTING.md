# Contributing

Thanks for your interest in contributing to ccamgr projects.

Contributions may include bug reports, feature suggestions, documentation improvements, and code changes.

## Issues

Before opening an issue, please check whether a similar issue already exists.

When reporting a bug, include enough information to reproduce the problem whenever possible.

## Pull Requests

Before submitting a pull request:

- Keep changes focused and reasonably small.
- Explain what the pull request changes and why.
- Test your changes where applicable.
- Update relevant documentation if necessary.

Project-specific contribution guidelines may override these general guidelines.
